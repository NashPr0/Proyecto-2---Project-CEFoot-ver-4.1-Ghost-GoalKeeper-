# Proyecto-2---Project-CEFoot-ver-4.1-Ghost-GoalKeeper-
El Proyecto II consiste en el diseño e implementación de un circuito lógico combinatorio, cuya  salida deberá transmitirse de forma inalámbrica entre la Raspberry Pi Pico W y la  computadora. En la computadora, los resultados se mostrarán a través de una interfaz gráfica,  la cual deberá integrarse con el juego desarrollado en el Proyecto I.
